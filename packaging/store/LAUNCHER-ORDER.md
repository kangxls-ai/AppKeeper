# Windows 1.3.5 标签排序与入口置顶

“全部”与自定义标签统一参与左右拖动排序，“全部”可放在任意位置且不可删除。使用独立内部键区分内置“全部”和同名自定义标签。旧配置默认保持原先顺序；调整后按保存顺序启动。

应用、文件、文件夹与网址入口可通过右键“置顶入口”固定到当前视图前面；已有置顶项提供“再次置顶（排第一）”和“取消置顶”。最近一次置顶排第一。“全部”、每个标签及分组视图独立保存置顶项，不改变其他标签或最近访问锁定项。置顶项之间的左右拖动更新置顶顺序，普通项目仍保留原有排序；取消置顶后回到普通排序中的位置。

布局备份包含 `LauncherTagOrder` 与 `LauncherPins`。导入旧版配置无需迁移；删除入口和标签会清理关联的置顶状态。Mac 原有置顶配置继续使用其本机设置文件，不做跨平台顺序迁移。
